# Console Feature Parity Matrix

Reference: the read-only original MY-CONSOLE `server.js` supplied for the parity review. Source locations below refer to function names / sections in that reference. TELIPHONES locations refer to this repository.

Status meanings: **Preserved (portable verified)** means implementation and portable source/emulator tests exist; **Partial** means a comparable feature exists but behavior is not identical or remains unverified; **Missing** means the original behavior has not been implemented; **Native verification required** means portable checks cannot establish Windows/MFC/SSH/UI behavior.

Native MFC rendering, ConPTY interaction and visual behavior require Windows acceptance. |

## Validation boundary

Portable CMake/CTest, emulator tests and `build_layout_test.py` validate terminal-model and source contracts only. They do not prove MFC compilation, native clipboard behavior, UI positioning, ConPTY display, Windows OpenSSH lifecycle, reconnect timing, or live PBX shell behavior. Those items remain **not verified** until the Windows build and interactive acceptance checklist pass. The original reference source was not modified.
