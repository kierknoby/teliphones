FreePBX / 0.6.4 local archive

Form correction packaged.
Listener failures made diagnosable.

Local TELIPHONES-0.6.4.tgz and its SHA-256 sidecar contain module 0.6.4, broker 0.6.3 and protocol 12. Packaging checks matched source when it was prepared. It contains pairing progress/error transport corrections and verified nftables transaction recovery.

Important source/package distinction

The 0.6.4 archive includes the web-only form correction and listener diagnostics, validated against module source. The preserved 0.6.3 archive has not been rebuilt and predates these changes. Neither package demonstrates successful live pairing.

No installation on a live FreePBX 17 / Debian 12 host or public release is established.

FreePBX / verification

Use the exact trusted package.

The 0.6.4 test archive/sidecar and unchanged 0.6.3 archive/sidecar are present locally. Older changelog versions are history, not an inventory of available downloads; no historical archive was recreated.

Verify before installing

For the preserved archive, with its matching trusted sidecar:

sha256sum -c TELIPHONES-0.6.4.tgz.sha256

A checksum establishes byte identity, not publisher trust or live readiness. Obtain a reviewed test package through the maintainer, not a source ZIP or an assumed public URL.

After Module Admin, repeat the documented root bootstrap with no active support session and workstation tunnels disconnected. Verify broker 0.6.3, protocol 12, all protected helpers and restart time. An older broker at protocol 12 still requires an update. Preserve firewall controls and recovery data.

Open Windows build workflow ↗Check Windows requirements

Artefact retention is 14 days. No current run, executable hash or publicly available 0.8.1 build is established here. Check build provenance rather than relying on a version string alone.

  • Keep TELIPHONES.exe and TELIPHONES-SSH.exe adjacent.
  • Read the included licence and OpenSSL licence.
  • Inspect build-info.json for source revision, run identity/attempt and executable hashes.
  • Expect unsigned test executables; verify trusted origin rather than disabling Windows protections.
  • Install/reuse official WireGuard separately; it is not bundled.

Earlier native test and live login results are operator-reported; native validation of the 0.8.1 MFC interface remains outstanding. GUI-only access needs no OpenSSH; managed SSH does.
