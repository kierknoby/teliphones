The local TELIPHONES-0.6.5.tgz and SHA-256 sidecar contain current module source. No publication or deployment is claimed. Windows 0.8.3 native validation and live-PBX acceptance remain separate gates. Review evidence and limitations.

FreePBX / 0.6.5 source

Durable revocation.
Verified access removal.

Module 0.6.5 and broker 0.6.5 retain protocol 12. Revocation is recorded before fallible cleanup, blocks restoration and heartbeat admission, verifies peer/firewall/SSH enforcement, and distinguishes unconfirmed removal from pending housekeeping and complete cleanup. Progress and persisted outcomes survive a disconnected browser.

Important source/package distinction

The local 0.6.5 archive includes the web-only form correction, listener diagnostics and latest revocation security corrections. The obsolete root-level 0.6.4 archive and checksum were removed. Historical archives do not represent current source.

No installation on a live FreePBX 17 / Debian 12 host or public release is established.

FreePBX / verification

Use the exact trusted package.

The 0.6.5 archive and matching checksum are available locally for review. The unrelated website ZIP and its checksum are unchanged. Do not treat a historical archive as containing the current security fixes.

Verify before installing

Verify the reviewed local 0.6.5 package against its matching trusted sidecar:

sha256sum -c TELIPHONES-0.6.5.tgz.sha256

A checksum establishes byte identity, not publisher trust or live readiness. Obtain a reviewed test package through the maintainer, not a source ZIP or an assumed public URL.

After Module Admin, repeat the documented root bootstrap with no active support session and workstation tunnels disconnected. Verify broker 0.6.5, protocol 12, all protected helpers and restart time. An older broker at protocol 12 still requires an update. Preserve firewall controls, recovery data and the revocation journal; older brokers do not understand these new security decisions.

No artefact yet.

The repository's Windows build workflow is configured to produce the separate TELIPHONES-Windows-x64 artefact after its checks succeed. Windows 0.8.3 source has not run through native compilation and SCM and real WireGuardNT regression tests, so there is no validated 0.8.3 artefact to download. The workflow link describes the build process, not a verified executable.

Open Windows build workflow ↗Check Windows requirements

Artefact retention is 14 days. No current 0.8.3 executable or live connectivity result is established. Check build provenance rather than relying on a version string alone.

  • Keep TELIPHONES.exe and TELIPHONES-SSH.exe adjacent.
  • Read the included licence and OpenSSL licence.
  • Inspect build-info.json for source revision, run identity/attempt and executable hashes.
  • Expect unsigned test executables; verify trusted origin rather than disabling Windows protections.
  • Install/reuse official WireGuard separately; it is not bundled.

Earlier native test and live login results are operator-reported; native validation of 0.8.3 remains outstanding. GUI-only access needs no OpenSSH; managed SSH does.
