The currently tested FreePBX module package is 0.8.3.15. Windows and FreePBX module versions are independent; they do not share a version number. Independent module version.
Separate from Windows.

The currently tested FreePBX module installation is 0.8.3.15. The module and its broker use their own version history, independent of the Windows application's 0.10.0 target, and retain protocol 12. Follow the existing installation and checksum guidance for the module package; that does not make Windows 0.10.0 available or accepted.

FreePBX 17 / Debian 12 prerequisites, explicit administrator approval, protected root-broker installation and independent console recovery remain important. Do not infer live acceptance beyond the verification evidence documented for the specific package and environment.

FreePBX / package status
