Test builds.
Not a production release claim.

The current development versions are FreePBX module 0.5.0 and Windows application 0.7.0 (file version 0.7.0.0). Their versions are independent. The Module Admin package does not include Windows, and a Windows build does not install the PBX broker.

0.5.0 is a locally validated experimental test package. Its real-PBX roaming, watchdog, Apache/TLS and lifecycle acceptance tests remain outstanding. Review the evidence and limitations before installation.

Repository and workflow links below are grounded in local files. Public availability, publication and artefact retention have not been checked. No direct release, package or executable download is assumed.

FreePBX / 0.5.0

The Module Admin package.

For FreePBX 17 / Debian 12. The reviewed local working tree contains TELIPHONES-0.5.0.tgz and TELIPHONES-0.5.0.tgz.sha256. All four package checks passed, covering metadata, checksum, extraction, source equality and historical archive integrity.

Local test package / Public download not established

These files have not been established as published at a public destination. No direct 0.5.0 download link is offered here. Obtain the exact package and trusted checksum from the maintainer's test distribution; do not substitute a source ZIP or an older release.

Verify before installing

With the matching trusted sidecar and package in the same directory:

sha256sum -c TELIPHONES-0.5.0.tgz.sha256

A matching checksum establishes byte identity, not independent trust in the publisher. Review source and provenance too. This is a locally validated installation package, not a production-ready release.

Historical 0.4.0 and 0.4.1 archives are preserved. Version 0.4.1 corrected intrusive INPUT placement; it does not contain 0.5.0's managed listener or custom-port support.

After upgrading through Module Admin, repeat the root bootstrap and verify the installed broker is 0.5.0/protocol 6. Do not disable FreePBX Firewall or enable Custom Rules as a workaround.

Windows / 0.7.0

A successful build artefact.
Not a made-up installer link.

The repository's Windows build workflow is configured to produce the separate TELIPHONES-Windows-x64 artefact after its checks succeed. If an appropriate successful run and retained artefact are available, download it there; GitHub may require sign-in. This is a workflow link, not a verified executable download.

Open Windows build workflow ↗Check Windows requirements

Artefact retention is 14 days. No current run, executable hash or publicly available build containing the latest changes is established here. Custom-port import, browser launch and Connection Health require an updated build from the current source, not merely any artefact labelled 0.7.0.

  • Keep TELIPHONES.exe and TELIPHONES-SSH.exe adjacent.
  • Read the included licence and OpenSSL licence.
  • Inspect build-info.json for source revision, run identity/attempt and executable hashes.
  • Expect unsigned test executables; verify trusted origin rather than disabling Windows protections.
  • Install/reuse official WireGuard separately; it is not bundled.

Earlier native test and live login results are operator-reported; updated native custom-port execution remains unverified. GUI-only access needs no OpenSSH; managed SSH does.

A repository source ZIP is not the Module Admin package and is not a prebuilt Windows application. Uncommitted development changes may not yet be visible in the public repository.
