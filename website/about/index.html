Purpose / People / Principles

Make access easier.
Keep authority explicit.

TELIPHONES is a FreePBX administration project: connect familiar tools to deliberate permissions, rather than making permanent access the easiest option.

Administration is a workflow.
Not just a tunnel.

For an independent administrator, useful remote access means more than a network route. It means knowing which PBX you are connected to, which account is approved, whether the service is reachable and when the authority ends.

For MSPs, customer approval and temporary support windows are different from everyday workstation pairing. TELIPHONES keeps those workflows separate while publishing the underlying contracts.

The project joins a native Windows application with a FreePBX module and a root-owned broker. It aims to reduce routine VPN, key and permission coordination without making secure configuration optional.

The repository identifies Kieran Knowles-Byrne (@kierknoby) as author, with maintenance by FreePBX UK. Source and its development history are available for inspection.

Alongside FreePBX.
Not endorsed by implication.

TELIPHONES targets FreePBX 17 on Debian 12 and genuine WireGuard for Windows. It does not replace FreePBX authentication, FreePBX Firewall, OpenSSH or the administrator's network policy.

It is a community module installed manually, not a module claimed to be included in the FreePBX online repository. No endorsement, certification or affiliation with Sangoma, the FreePBX project, WireGuard or another organisation is asserted here.

The experimental software is not production-ready. Initial live SSH and native tests are meaningful milestones, but not independent audit or complete lifecycle assurance. The evidence register makes that distinction explicit.

A quiet website.
No background product connection.

This is static HTML, local CSS, JavaScript and labelled illustrations. There are no analytics, external scripts/fonts, embedded services or application connections. The theme/filter/checklist work locally; they are not system checks.

The interactive demonstrations use synthetic data stored in this browser's localStorage; Reset Demo clears that sample state. They are simplified illustrations, not screenshots, real cryptography, PBX connections or native GUI evidence. Other pages set no cookies or browser storage. Hosting may retain normal access/security logs, and external links leave this site.

Content is reviewed against Windows 0.8.5, module 0.6.7, broker 0.6.7 and protocol 12 source on 6 November 2026. Current 0.6.7 source adds correlated admission diagnostics and responsiveness corrections, retaining the prior revocation and firewall fixes; the local 0.6.7 archive and checksum include current source, and the existing 0.6.6 archive remains unchanged. Windows 0.8.5 has no native validation or application artefact yet, and the embedded SSH console crash remains a release blocker. Local website edits have not been deployed.
