01 / Less coordination

Remote administration,
with the pieces connected.

A manually configured VPN gets you a route. You still need to coordinate who may use it, which services they can reach, their SSH credentials and when access should end. TELIPHONES makes those decisions part of the PBX workflow.

Approval

Pair a workstation.
Not a whole network.

A full FreePBX administrator approves one key-bound request, with web-only or explicitly authorised SSH access. The workstation gets a host route to that PBX.

How pairing works →
Identity

Open SSH.
Not a key-sharing exercise.

Managed SSH uses an approved existing account, pinned host identity and a temporary certificate for a fresh session key. No permanent administrator key needs to be handed to the workstation.

Inside managed SSH →
Authority

Set a lifetime.
Keep the decision on the PBX.

Choose temporary access or persistent approval until revoked. Reconnecting does not renew the original deadline. Removing a local profile does not revoke the PBX pairing.

03 / A deliberate exchange

Request. Approve.
Connect. Work.

There is no background service deciding who should have access. Pairing is an explicit exchange between the workstation and a full administrator on the PBX.

  1. Request

    Generate a pairing request in Windows. Opt in to SSH only if you need it.

  2. Approve

    The PBX administrator sets the lifetime and, for SSH, deliberately selects an existing account.

  3. Connect

    Import the bound response and establish WireGuard to the PBX's reachable UDP endpoint.

  4. Work

    Open FreePBX or authorised SSH. Disconnect locally; revoke authority on the PBX when finished with the pairing.

04 / A separate support workflow

A customer's support window.
Not your workstation pairing.

Remote Support is for temporary, customer-authorised engineer access. It uses separately operated Connect, Checker and Console integrations, with an absolute support deadline and independent reachability evidence.

Contracts and laboratory components exist. A complete production-validated service does not. No hosted gateway or relay is supplied.
