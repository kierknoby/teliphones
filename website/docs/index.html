This site explains the workflow and links the complete guide; privileged bootstrap commands are deliberately not abbreviated here. Match instructions to the trusted build.

Independent targets: Windows 0.8.3, module 0.6.6, root broker 0.6.6, protocol 12. Repeat root bootstrap after Module Admin and verify all protected helpers. An older protocol-12 broker is still incompatible.

Current 0.6.6 source adds durable revocation and verified removal; the local 0.6.6 archive and checksum include current source. The superseded 0.6.5 archive was removed; historical archives lack those new security corrections. Windows 0.8.3 native validation and live pairing remain separate gates.
